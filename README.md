# 🎞️ Animação com CSS

Este projeto tem como objetivo apresentar animações criadas exclusivamente com **CSS**, sem uso de JavaScript. Ele foi desenvolvido como parte de um desafio ou prática de aprendizado para explorar transições, transformações e keyframes no CSS.

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3 (com uso de animações e keyframes)

## ✨ Recursos e Efeitos Utilizados

- `@keyframes` para animações customizadas
- `transition` e `transform` para suavizar efeitos
- Movimento e interação visual com apenas CSS

## 🎓 Aprendizados

- Com este projeto, foi possível praticar:
- Criação de animações com @keyframes
- Controle de tempo e fluidez com animation-duration, delay, timing-function
- Estilização de elementos animados com CSS puro
